# Support

Use GitHub issues for reproducible bugs and feature requests. Include the TRIZ version, Node version, OS/architecture, command, expected result, and a minimal redacted analysis request. State whether the run was offline or live. For classifier issues include a redacted verdict and evidence IDs.

Do not post API keys, authentication files, private source, or proprietary analysis evidence. Review persisted results before sharing them. Read the README for installation, taxonomy, uncertainty handling, and catalog limitations. This community project has no guaranteed support response time.
