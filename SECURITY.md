# Security

TRIZ sends supplied evidence to a configured classifier during live analysis. Validate analysis requests and review recommendations before using them. Classifications are probabilistic and catalog suggestions are heuristics. Provider prompts and context may leave your machine. Keep secrets out of task contracts and artifacts.

## Reporting a vulnerability

Use the repository's GitHub **Security → Report a vulnerability** private reporting channel if available. Otherwise contact Matthew Cochran at matthew@cochranweb.com and request a private reporting channel before sending sensitive details. Do not publish credentials, exploit details, or private transcripts in public issues.

Include the affected version, impact, and a minimal reproduction without secrets. Security fixes target the latest release; older versions have no guaranteed support window. Response times are not guaranteed. For ordinary bugs, use the issue tracker.
